# Соня — трекер сна малыша

Локальный русскоязычный PWA-трекер сна нескольких детей. Данные и фотографии хранятся только в браузере (IndexedDB), без аккаунтов и аналитики.

## Запуск

```bash
npm run dev
```

Откройте `http://localhost:5173`. Установка зависимостей не требуется. Для production-проверки используйте `npm run build && npm run preview`.

## GitHub Pages

Сборка использует относительные пути и работает как project site по адресу вида `https://<user>.github.io/-baby-sleep-tracker/`. Перед публикацией проверьте её командами:

```bash
npm run build
npm run test:pages
```

## Возможности

- таймер «Уснул / Проснулся», восстанавливающийся после перезапуска;
- ручной учёт дневного и ночного сна, качества, места, способа засыпания и пробуждений;
- несколько локальных профилей детей;
- история в виде списка, суточной шкалы и календаря;
- статистика за сегодня, вчера, неделю, месяц и выбранный диапазон;
- персональный ориентир следующего сна;
- светлая и ночная темы, адаптивный интерфейс;
- CSV, печатный PDF-отчёт, JSON-резервная копия и восстановление;
- устанавливаемая PWA с офлайн-оболочкой.

> Возрастные ориентиры носят информационный характер и не заменяют рекомендации педиатра.
